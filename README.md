# 🛡️ Phishing Email Detection Model

A Machine Learning-based application that detects phishing emails using Natural Language Processing (NLP). The project analyzes email text and predicts whether an email is **Legitimate** or **Phishing** using TF-IDF feature extraction and Scikit-learn classifiers.

---

## 🚀 Features

- 📧 Detects phishing emails
- 🤖 Machine Learning classification
- 🔍 TF-IDF text feature extraction
- 🌐 URL detection from email content
- 📊 Accuracy evaluation
- 📈 Confusion Matrix visualization
- 🖥️ Simple GUI built with Tkinter

---

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/shivarjunchaturvedi/Phishing-Email-Detection.git
```

Move into the project

```bash
cd Phishing-Email-Detection
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python main.py
```
